 Student Grade Management System 📚

A simple Student Grade Management System built entirely using Python. This project helps manage student records, calculate academic performance, and assign grades automatically.

🚀 Features

- Add Student: Enter student name, roll number, and subject marks.
- Calculate Grades: Automatically calculates total marks, percentage, and grade.
- Display Records: View all registered student details.
- Search Student: Find student records using their roll number.
- Delete Student: Remove student records.
- Interactive Menu: Easy-to-use menu-driven interface.

🛠️ Technologies Used

- Python 3
- Built-in Python functions and modules

📖 Python Concepts Used

- Variables and data types
- Lists and dictionaries
- Functions
- Conditional statements (if-elif-else)
- Loops (for and while)
- Exception handling
- List operations

⚙️ How to Run

1. Clone this repository:
   
   git clone YOUR_REPOSITORY_URL

2. Open the project folder.

3. Run the Python file:
   
   python student_manager.py

4. Follow the instructions displayed in the terminal.
